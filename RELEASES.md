# VitaFlightRadar Releases ✈️

## 🟢 Current recommended release

### [VitaFlightRadar V2.5](https://github.com/1000660928-design/VitaFlightRadar/releases/tag/v2.5)

**Recommended for both PS Vita PCH-1000 FAT/OLED and PCH-2000 Slim.**

- Original public build date: **October 4, 2026**
- Status: **Latest / Recommended**
- Real-hardware tested
- Includes persistent map position/zoom, TRACK FLIGHT, improved tracking stability, aircraft-heading compass, broader flight search and improved satellite-map behavior

## 🧰 Compatibility fallback

### [VitaFlightRadar V1.9.3](https://github.com/1000660928-design/VitaFlightRadar/releases/tag/v1.9.3)

- Can be used on either PCH-1000 or PCH-2000
