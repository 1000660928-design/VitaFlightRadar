# VitaFlightRadar Releases

This page is the release index for VitaFlightRadar.

## Latest release

### v1.7

**Recommended version**

[Download VitaFlightRadar v1.7 VPK](releases/VitaFlightRadar-v1.7.vpk)

Highlights:

- World-map mode removed
- Pinch-only map zoom
- Pinch zoom and aircraft search radius unified into one feature
- Zooming in shows aircraft only inside the tighter visible area
- Zooming out expands the live aircraft search area
- Higher-resolution satellite tiles are loaded after zoom so the map does not remain permanently stretched or blurry
- Hardware zoom/radius buttons removed
- SELECT-to-exit removed
- Coordinate search, AUTO/MANUAL refresh, START refresh, tap-to-select and UP/DOWN aircraft selection retained
